# MBR Agent Prompt Recommendations

This folder stores dated recommendation files drafted by the monthly SRT MBR Cursor agent after each run.

## Purpose

The agent does **not** edit the live prompt automatically. It writes learnings here (or as a Notion child page) for human review. Merge accepted changes into:

- `docs/srt-mbr-monthly-automation-prompt.md`
- `docs/srt-mbr-notion-url-addon-prompt.md`
- `docs/srt-mbr-prompt-self-improvement-addon-prompt.md`

## Naming convention

```
YYYY-MM-DD.md
```

Example: `2026-07-01.md` for a run executed on 2026-07-01.

## Review workflow

1. Open the latest `{run_date}.md` after each monthly run
2. Triage REC items (High → Medium → Low)
3. Merge proposed prompt text into the canonical prompt files
4. Check the reviewer checklist at the bottom of the recommendations file
